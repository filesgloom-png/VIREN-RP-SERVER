# VIREN RP — Server

Open.mp-based GTA San Andreas RP server.

## Current stage
- Server-only development.
- Modular Pawn architecture.
- GitHub Actions build pipeline.
- Android client and launcher postponed.

## Roadmap
Registration → authentication → accounts → characters → economy → jobs → factions → vehicles → houses/businesses → inventory → admin → logs → anti-cheat.

## Build
GitHub Actions validates the gamemode and uploads the compiled AMX artifact.
